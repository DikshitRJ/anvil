# `src/core/context/bm25.ts`

**Purpose**
Incremental BM25 (k1 = 1.2, b = 0.75) over an inverted index of token lists.

**Exports**
- `Bm25Index`: `add(id, tokens)`, `remove(id)`, `search(queryTokens, k)`, `size()`.

**Collaborators**
- Imports: none.
- Used by: `codeIndex.ts` (one document per chunk).

**Key behaviour and invariants**
- `add` on an existing id first removes it, so re-adding replaces the document.
- `remove` of an unknown id is a no-op; it also deletes empty postings and subtracts the document length from the running total.
- `search` returns `[]` for an empty index. Query terms are de-duplicated; `idf = ln(1 + (n - df + 0.5) / (df + 0.5))`; average length defaults to 1 if it computes as 0.
- Results are `{id, score, matched}`, sorted by score descending then id ascending (deterministic), cut to `k`.

**Notes**
- `matched` lists the query terms that hit the document.

- Nonpositive result limits return an empty array.
