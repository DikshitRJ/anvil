# `src/core/context/bm25.ts`

**Purpose**
This file implements the BM25 ranking algorithm for information retrieval. It manages an inverted index to calculate relevance scores for search queries.

**Exports**
* Bm25Index(none): class - It manages a collection of documents and calculates search scores.

**Collaborators**
* Imports: Not visible from this file.
* Exports: Not visible from this file.

**Key behaviour and invariants**
* The class uses constant values K1 = 1.2 and B = 0.75.
* The `add` method removes an existing document if the ID already exists.
* The `remove` method returns early if the document ID does not exist.
* The `search` method returns an empty array if the index contains no documents.
* The `search` method sorts results by score in descending order.
* The `search` method sorts results by ID in ascending order if scores are equal.
* The `search` method limits the output to k results.
* The `totalLen` variable tracks the sum of all token counts in the index.

**Notes**
* The `avg` calculation defaults to 1 if the number of documents is zero.
* The `idf` calculation uses a smoothing factor of 0.5.
